How to Compile and Run

First, check that Java is installed:
```txt
java -version
javac -version
```
Compile a program using:
```txt
javac ProgramName.java
```txt
Run the compiled program using:
```txt
java ProgramName
```txt
For example:
```txt
javac BubbleSort.java
java BubbleSort
```
